# Dhanvin Assets – Premium Wealth Advisory Website

A complete, production-ready wealth advisory website built with pure HTML, CSS and JavaScript.

🌐 **Live Site:** [dhanvin-assets.vercel.app](https://dhanvin-assets.vercel.app)

---

## Pages

| Page | Description |
|------|-------------|
| `/index.html` | Homepage – Hero, SIP Calculator, Testimonials, FAQs |
| `/about.html` | About Us – Founder, Timeline, Values, Team |
| `/contact.html` | Contact – Booking form, Map, WhatsApp |
| `/calculators.html` | 5 Calculators – SIP, EMI, Retirement, Education, Goal |
| `/market-insights.html` | Market data, articles, weekly reports |
| `/blog.html` | Blog with category filter and search |
| `/faq.html` | Full FAQ with 6 categories |
| `/services/*` | 8 dedicated service pages |

## Features

- 🎨 Deep Purple + Royal Blue + Gold design system
- 🌙 Dark / Light mode with localStorage
- 📈 Live stock ticker (NIFTY, SENSEX, GOLD)
- 🧮 5 interactive financial calculators with Chart.js
- 📱 Fully responsive (mobile-first)
- ✨ AOS scroll animations throughout
- 💬 Floating WhatsApp button
- 🔢 Animated counters
- 🎯 SIP vs Age comparison animation

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- [Chart.js 4](https://www.chartjs.org/) – Calculators
- [AOS](https://michaelorchard.com/aos/) – Scroll animations
- [Font Awesome 6](https://fontawesome.com/) – Icons
- [Google Fonts](https://fonts.google.com/) – Poppins, Inter, Manrope
